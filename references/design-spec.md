# 设计规范（从原模板采样）

本文件是「示例环保公司简介」模板的视觉说明书。数值不是估计值：颜色来自对模板 XML 填充与 logo 像素的采样，
字号/位置来自模板形状几何。改版式前先读这里。

## 1. 画布

| 项 | 值 |
|---|---|
| 尺寸 | 13.333 × 7.5 in（16:9） |
| 安全边距 | 左右 0.95 in，上 0.30 in，下 0.60 in |
| 内容区 | `(0.95, 1.30, 11.43, 5.55)`，即 `CONTENT_BOX` |
| 页标题 | 基线框 `(0.80, 0.30, 10.4, 0.62)`，28 pt 加粗，左对齐 |
| 标题箭头 | 4 个 V 形 + 1 个五边形，从 `(0, 0.487)` 起，单个 0.185×0.238 in |
| 徽标 | `(11.91, 0.374)`，0.687 × 0.703 in |
| 页码 | `(12.70, 7.075, 0.45, 0.26)`，14 pt，右对齐，`#7F7F7F` |

### 渐变配方（照抄即可）

| 用途 | 渐变 |
|---|---|
| 品牌强调线 / 标题下划线 | `#2FCF9D → #33AC48`，90°（横线用 0°） |
| 目录大色带 A（底） | `#50C563`(16%) → `#459753`，90° |
| 目录大色带 B（上） | `#67BB3E` → `#44C8A2`(45%)，140° |
| 目录卡片 | `#9FC4EE → #DCEAF8 → #FFFFFF`，140° + 蓝色柔光 |
| 底部绿带 | `#2FCF9D`(75%) → `#33AC48`(95%)，135° |
| 流程箭头 | 依次 `#2FCF9D→#50C563`、`#50C563→#33AC48`、`#33AC48→#214B0D`、`#44C8A2→#459753` |
| 结尾信息条 | `#4CB268 → #2F8E4E`，0° |

> 禁止：红色系（`#C00000` `#FF0000` 等旧模板强调色）、纯黑大面积、以及上表之外的杂色。

## 3. 字体与字号

- **唯一字族：微软雅黑**（`FONT`）。中文与西文都用它，`a:latin` 与 `a:ea` 都要写。
- 层级：

| 层级 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 封面主标题 | 44~46 | Bold | `#222222` |
| 封面副标题 | 17 | Regular | `#404040` |
| 章节页大数字 | 84 | Bold | `#BFBFBF` |
| 章节页标题 | 44 | Bold | `#404040` |
| 页标题 | 28 | Bold | `#404040` |
| 卡片标题 / 小标题 | 18~20 | Bold | `#404040` |
| 正文 / 要点 | 15~16 | Regular（要强调时 Bold） | `#404040` |
| 指标数值 | 34 | Bold | `#33AC48` |
| 注释 / 图注 | 11~13 | Regular | `#7F7F7F` |
| 英文装饰（CONTENTS 等） | 28 | Regular | `#BFBFBF`，字距 +6 |

- 行距：正文 1.35~1.45；标题 1.1~1.15；英文装饰 1.0。
- 中文标点用全角（「」、，、。）；英文缩写不与中文混排时加空格（`10 亿元`）。

## 4. 形状语言

| 元素 | 做法 |
|---|---|
| 标题箭头 | 五边形 + 4 个 V 形（`adj≈0.504`），渐变绿，透明度 95% |
| 底部绿带 | 左下角自由多边形 `(0,6.92) → (5.35,7.5) → (0,7.5)`，渐变绿 |
| 目录色带 | 两个大 V 形箭头（`adj=0.5`）：`(4.54,0,6.76,7.5)` 与 `(6.36,0.70,5.50,6.10)` |
| 目录卡片 | 圆角矩形 6.427×0.93，圆角 0.155，蓝白渐变 + 四向蓝柔光 |
| 卡片 | 白底、圆角 0.10、蓝柔光阴影；顶部配图只圆上两角；标题下加渐变短线（宽 ≤1.55） |
| 章节绿尖角 | 五边形 `(0, 2.445, 0.586, 1.827)`，纯 `#33AC48` |
| 横幅 | 双尖头多边形（左右各 0.32 in 尖角），绿色渐变，白字 20 pt |
| 表格 | 表头 `#33AC48` 白字 12 pt 加粗；斑马纹 `#FFFFFF` / `#F5FAF7`；仅保留 `#DCE6F0` 行线 |
| 标签 | 胶囊形，高 0.36，主绿底白字 |
| 提示条 | `#E8F5EC` 底 + 左侧 0.07 in 绿色竖条 |

## 5. 图片规则

- 一律 `pic()`：自动 object-fit 裁切，圆角可选，透明 PNG 保留 alpha。
- 内页配图圆角 0.10~0.14；卡片顶图 0.10。
- 照片基调：绿色自然（草地/树叶/城市绿化/生态）。避免冷蓝科技图、灰色工业图、真人特写。
- 封面、结尾只用 `assets/` 里的预合成底图，保证色调统一。

## 6. 页面骨架比例

- 封面：字标区（0.4~1.9）→ 主标题（1.9~2.9）→ 强调线（2.97）→ 副标题（3.12）→ 地点/日期（6.48，白色加粗 24）。
- 内容页：标题区 0~1.0；内容 1.30~6.85；底部绿带与页码不与内容重叠。
- 章节页：大数字 + 标题落在左侧 0~7.2，照片铺满，左侧用白色渐变过渡。
- 结尾页：致辞字标 2.43~3.38，英文 3.52，绿色信息条 6.27~7.50，二维码 5.77 起。
